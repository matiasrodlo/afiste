# Afiste: Tokenized Venture Capital Marketplace

Afiste is a fintech platform for venture capital that tokenizes VC portfolios and enables a marketplace for VC assets improving liquidity and broadening investor access.

Built in July–December 2020 during an acceleration program at the **UC Innovation Center** (Pontifical Catholic University of Chile, N°1 in LATAM). Selected **Top 20** out of 800+ Latin American projects.

Advised by [Dr. Nelson Andrade Valbuena](https://facea.ucsc.cl/autoridades/dr-nelson-andrade-valbuena/). We met twice weekly at the **University of Chile Business School, PhD thesis floor** with the team (Emiliano Araneda, Kurt Müller, Mauro Pérez).

## Features
- VC fund tokenization
- Secondary marketplace
- Real-time NAV tracking
- KYC/AML compliance
- Web3 integration

## Tech Stack
TypeScript · React · Node.js · PostgreSQL · Solidity

## Quick Start
```bash
# Backend
cd backend
npm install
npm run prisma:migrate
npm run prisma:demo
npm run dev

# Frontend
cd frontend
npm install
npm start
```

**Refactored in 2025 from Ruby/Rails to Node.js/TypeScript with React.**
